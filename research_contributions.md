1.6 Research Contributions

This study aims to make the following contributions to the empirical evaluation of security in MCP-based multi-agent systems:

Multi-Agent Experimental System: A documented implementation comprising Planner, Research, Execution, and Evaluation agents, with MCP-based tool interaction and configurable security controls.
Repeatable Evaluation Framework: A structured framework for evaluating system security and performance across multiple security configurations using defined experimental procedures and evaluation metrics.
Normal and Adversarial Test Cases: A collection of normal-task and adversarial test cases covering direct prompt injection, indirect prompt injection, tool-output poisoning, and unauthorized tool invocation.
Empirical Comparison of Security Configurations: An experimental comparison of three security configurations using attack success rate, security breach rate, task completion rate, response quality, and latency.
Evidence-Based Security Recommendations: Recommendations derived from the experimental findings regarding the effectiveness of security controls and their associated performance trade-offs under the tested conditions.

Note: These are the study's intended contributions. Following Phase 3, this section must be revised to include only contributions that were actually implemented, evaluated, and supported by experimental evidence.
